Ini-abasi Etim — Backend Software Developer
============================================

Personal portfolio site: https://initech-step.github.io/

Structure
- index.html            Home: hero, about, skills, selected work, contact
- proj1.html, zuvote.html, inventory.html, ese.html, note.html
                        Project detail pages
- assets/css/style.css  All site styles (design tokens live at the top in :root)
- assets/js/main.js     Navigation, scroll behaviour, preloader, scroll reveals
- assets/presentations/ CV and project presentation PDFs

Viewing locally
Open index.html in a browser, or from this folder run:
    python -m http.server 8000
and visit http://localhost:8000
